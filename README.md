# PERSONAL VIDEO EDITOR — V1 Preview · 1.12.0

フォトグラファーのためのローカル動画編集アプリ。Webの編集画面と、Macで動くネイティブFFmpegエンジンを同梱しています。

**1.10.0を安定復帰点として固定し、1.12.0を自動試験とChrome操作確認を通過した現在版とします。** H.264/SDR実写素材、`IMG_7917.mov` のHEVC/SDR/VFR実写素材、合成素材でMac処理を検証しています。iPhone 16 Pro Safari・実写HDRの受け入れ試験は未実施です。

## 1.12.0 — STABLE EXPORT / TRACK CONTROL

- 端末内書き出しの動画フレームを、再利用される列挙用Canvasの保持から、出力時刻ごとの明示取得へ変更しました。VFRを含むソース時刻を各出力フレームへ反映します。ChromeのWebCodecsで1秒・30fpsのMP4を実生成し、30フレームの全数、H.264/AAC、全尺デコード、0.08／0.48／0.88秒の画像差を確認しました。
- タイムライン左端へV1〜V3の表示スイッチと、A1〜A4のミュート・0〜200%音量を配置しました。設定はプロジェクト、自動保存、ブラウザ書き出し、Mac FFmpeg書き出しへ保持されます。
- Shiftで選択した複数の動画、音声、FX、テキストは、ドラッグ時に相対位置を保ってまとめて移動します。映像の上下トラック移動も同じ選択群へ反映します。
- `UNDER`ルックと、解析した平均輝度・明暗幅・クリップ率から露出、黒、ハイライト、彩度を提案する`CINEMA UNDER`を追加しました。解析後も自動適用せず、利用者がボタンを押した場合だけ反映します。

Chrome 1440×960でトラック操作と配置を確認し、JavaScript例外はありません。iPhone 16 Pro Safari、Mac Safari、実写HDR、実写手ぶれ補正、長時間連続編集は未検証です。

## 1.10.0 — FLEXIBLE TIMELINE

- MEDIAの動画・写真・音声を、ブラウザ版でもV1〜V3／A1〜A4の任意位置へ直接ドラッグできます。素材カードの×から一覧と配置済みクリップを外せます。元ファイルは変更しません。
- 映像・音声・FX・テキストをShiftで複数選択し、⌘C／⌘X／⌘V／⌘D／Deleteを共通操作として使えます。Optionを押しながらタイムライン項目をドラッグすると、その場で複製して移動します。
- 映像・写真の不透明度、透明からのフェードイン、透明へのフェードアウトをCUTにも配置しました。プレビュー上のドラッグで位置を動かし、中央では縦横ガイドへ吸着します。
- 同じトラックの前後素材との間隔が揃う位置では「等間隔」を表示して吸着します。トラックパッドのピンチはタイムラインの細かさを1〜10倍で変更し、ページ全体の拡大を抑止します。
- テキストはブラウザで利用できる候補フォントを選択でき、任意色のカラーピッカーへ変更しました。文字の輪郭は常に無効です。

Chrome 1440×1000の自動操作で、複数選択、FX／テキスト同時コピー・貼り付け、素材のドラッグ配置と削除、タイムラインピンチ相当、プレビュー位置操作を確認しました。JavaScript例外はありません。Safari実機のトラックパッド操作、iPhone 16 Pro、長時間編集は未検証です。

## 1.9.1 — MAGNETIC FX TIMELINE

- FXパレットのCamera Flash／Black FadeをFXトラックへドラッグし、任意時刻へ直接配置できます。配置済みFXとテキストもタイムライン上で横方向に移動できます。
- 「吸着」が有効な間は、再生ヘッド、映像・音声クリップの端、ほかのFX・テキストの端へ8画素以内で吸着します。アイテムの先頭と末尾の両方を判定し、Altキーで一時的に解除できます。
- 素材のドラッグ配置と通常クリップの移動も再生ヘッドへ吸着し、吸着位置をタイムライン全高のガイドで表示します。

## 1.9.0 — ENGINE / MEDIA WORKFLOW

- 読み込みとタイムライン配置を分離しました。素材はまずMEDIAへ入り、自動配置されません。Mac版ではカードをV1〜V3へドラッグし、任意位置へ配置できます。ボタン配置も利用できます。
- IMPORTのMEDIAを行型カードへ整理し、種類、寸法、使用箇所、再リンク状態、配置先を同じ視線で確認できます。リストはパネル内で独立して縦スクロールします。
- 音声分離は映像との連動が既定です。移動、IN/OUT、速度、分割、削除、複製が追従します。SOUNDから連動を解除すると独立編集でき、再連動時は映像の位置と範囲へ揃えます。音量、ミュート、フェードは常に個別調整できます。
- MacエンジンにProRes 422 LT / 422 / 422 HQのMOV書き出しを追加しました。10bit 4:2:2映像と24bit PCM音声を使います。端末版はH.264/AAC MP4です。
- 高品質スローはFFmpeg `minterpolate` の双方向動き推定と動き補償を使います。長い区間では処理時間が大きくなるため、必要な短い区間への使用を推奨します。
- 手ぶれ補正は検出精度を上げ、用途別の解析強度、ガウス平滑化、適応ズーム、bicubic補間を使います。`vidstab`を含むFFmpegが必要です。
- カラーは露出0.01段、その他0.1刻みへ細分化しました。Macエンジンは32bit float RGBで33点3D LUTを処理し、10bit ProResへ保持します。8bit H.264への変換時は誤差拡散ディザリングを使い、滑らかな階調の段差を抑えます。
- 上部にUndo / Redoを追加し、開く・保存・書き出しを同じ高さと書式に揃えました。右クリックメニューにもUndo / Redoがあります。
- クリップ尺を「つまんで伸縮」するGRAB TIME操作は廃止しました。タイムライン全体のピンチ拡大・縮小は引き続き利用できます。
- 日本語テキストはブラウザのCanvasで透過PNGへ描画してFFmpegのoverlayへ渡すため、`drawtext`がないFFmpegでも利用できます。外部プラグインやCDNへの依存は追加していません。

## iPhoneで編集する

1. アプリのURLを **Safari** で開きます。
2. 「動画を選択」から写真ライブラリまたはファイルを開きます。再開用の素材も、この端末内に保存します。
3. CUT / MOTION / LOOK / SOUND / FX / TEXTで編集します。並び替えはCUTの「前へ」「後へ」で行えます。
4. 「書き出し」→「この端末でMP4を書き出す」。まず1080p・30fpsを推奨します。処理中はSafariを開いたままにしてください。
5. 完成後「写真・ファイルへ保存」→iOSの共有画面の「ビデオを保存」または「ファイルに保存」。共有できないブラウザではダウンロードリンクを使います。
6. IMPORTの「前回のMP4を開く」から保存をやり直せます。「端末版の対応状況」では1秒の合成素材を使う端末テストも実行できます。
7. 「端末内の保存容量」では使用量を確認し、一覧から外した素材コピーや直近以外の書き出しを自分で整理できます。端末テスト用MP4と、前回より古い通常書き出しは自動で整理します。

**iPhone実機の受け入れ試験は未完了です。端末版ではHDRの正確なSDR変換は未対応で、速度変更した原音は音程も変化します。手ぶれ補正は平行移動のみです。** 対応しない素材やコーデックは停止し、編集内容を保持します。詳細はVALIDATION.mdを参照してください。

写真ライブラリの原本は変更しません。プロジェクトの「保存」は編集JSONを共有・ダウンロードします。動画本体は含まれません。端末のブラウザデータ削除に備え、元素材と完成MP4は写真/ファイルに残してください。

## Macで起動する

1. ZIPを展開し、フォルダ全体を任意の場所に置いてください。
2. Python 3.9以降と、libx264・overlay・zscale・tonemap・vidstabを含むFFmpegが必要です。文字はブラウザで透明PNGへ描画してから合成するため、通常はFFmpegのdrawtextを必要とせず、日本語も画面と同じフォントで書き出せます。Homebrewを導入済みの場合、以下をターミナルへ貼り付けます。

```bash
brew install python ffmpeg-full
```

3. `Launch.command`を開きます。同じ編集画面がブラウザに開きます。FFmpegは同梱していません。
4. 開かない場合はターミナルへ `bash ` と入力し、続けて `Launch.command` をドラッグしてEnterを押してください。macOSが確認を表示する場合は、内容と配布元をご確認のうえ開いてください。
5. 終了は起動したターミナルで **Control+C** です。起動中はターミナルを閉じないでください。

Homebrew未導入の場合は [brew.sh](https://brew.sh/) の公式手順で導入してください。インストール済みの通常版FFmpegも利用できますが、手ぶれ補正・HDR変換・テキストはビルド構成に依存します。起動スクリプトは `ffmpeg-full` のインストール先を優先します。

## 最初の編集

1. 「読み込む」からMOV/MP4/MXF、静止画、音声をMEDIAへ追加。Mac版は原本のコピーを保存し、SDRの720p・30fpsプロキシとサムネイル・音声波形を生成します。読み込み後、配置ボタンまたはMEDIAからV1〜V3へのドラッグでタイムラインへ置きます。
2. タイムラインをクリックしてクリップを選択。I / O、分割 S、トリム、並び替えを使います。通常削除は黒の空白を残し、前詰め削除は空白を作りません。タッチ操作ではタイムライン上を2本指でつまみ、時間目盛りの細かさを1〜10倍で変更できます。
3. MOTIONで0.05〜20倍速とランプの始点・終点・カーブを設定します。区間は分割で作ります。
4. LOOKでカラー、SOUNDで原音とBGM、TEXTで文字を調整します。
5. ANALYZEで素材全体の候補を表示。Intentを変更したときは再スキャンしてください。候補のボタンを押すまで映像は変更されません。
6. 「処理プレビューを生成」で、カラー・手ぶれ補正・補間・音声を含む540p出力を確認できます。
7. 書き出しでH.264/AAC・SDR MP4、またはMac版のProRes 422 / PCM MOVを生成し、保存リンクを押します。

Web上の端末版では、対応コーデックの素材の編集・近似試写・解析・プロジェクト保存・端末内MP4書き出しを利用できます。Macエンジンにはネット越しに接続しません。正確なHDR変換とvidstab補正はMac版で行います。

## 保存と再開

編集はブラウザへ自動保存し、Mac版ではディスクにも保存します。「保存」または⌘Sで `.project` ファイルをダウンロードできます。ファイルには編集内容と素材の参照が含まれ、動画本体は含みません。

別のブラウザやMacへ移す場合は、.projectを開き、元と同じファイル名・サイズの素材を読み込んで再リンクしてください。Mac版の「開く」では保存済みプロジェクトも選べます。編集履歴は最大60回で、ブラウザを閉じるとリセットされます。

### Mac内の保存先

`~/Library/Application Support/Personal Video Editor/`

- `media/`：読み込んだ動画・BGMのコピーとメタデータ。元の場所の原本は変更しません。
- `cache/`：プロキシ、サムネイル、波形、解析結果、処理プレビュー。
- `projects/`：自動保存したプロジェクト。
- `exports/`：完成MP4 / MOV。
- `logs/`：処理段階・所要時間・検証結果・FFmpegエラーの診断記録。失敗画面からダウンロードできます。

RAMを抑える代わりにディスクを使用します。元ファイルのコピー、プロキシ、スタビライズ中間映像、音声の一時ファイルを保存できる空き容量が必要です。成功・失敗・キャンセル後、書き出し中間フォルダは削除します。生成中は一時ファイルを使い、検証に通った出力だけを確定します。生成ファイルが不完全な場合は1回だけ再生成します。入力形式や設定のエラーは自動再試行しません。最終MP4は全尺をデコードして検証するため、その分だけ完了まで時間がかかります。

不要なキャッシュはアプリ終了後にFinderから削除できます。次回IMPORTの「プロキシを生成 / 再試行」で再作成してください。`media/` と `projects/` は必要なプロジェクトが参照していないことを確認してから整理してください。原本・完成MP4・.projectのバックアップを推奨します。

## 既知の制約・未検証

- 実機のiPhone HEVC/HDR/Dolby Vision、長尺VFR、Safariでの再生、Apple Siliconでの性能、Instagram実投稿は未検証です。合成素材によるネイティブ処理試験を同梱しています。
- HDRはHLG/PQベースレイヤーの変換です。Dolby Vision動的メタデータは処理しません。Profile 5または伝達関数不明のHDRは停止します。HDR出力はありません。
- プロキシは30fpsです。高FPS/VFRの1フレーム送りは平均FPSによる時刻移動で、原本の厳密なフレーム選択は未対応です。
- 極端な速度のブラウザ試写はシーク駆動による近似です。0.25倍未満・4倍超の原音は試写中ミュートします。最終レンダリングはPTS基準です。
- ランプは32分割近似です。音声は区間ごとにピッチを維持して処理しますが、急変部や極短区間では音のつなぎ目が聞こえる場合があります。BGM主体の演出では原音ミュートを選べます。
- ランプを分割すると区間ごとにイージングが再計算されます。分割前の厳密なカーブ形状は保存されません。Bezier編集は未実装です。
- GPUとFFmpegは共通のRGB補正式を使います。LUT補間・圧縮・表示色管理による差は残ります。手ぶれ補正・ブレンド・1.0を超える音量も処理プレビューで確認してください。
- 手ぶれ補正の事前クロップ推定・光学フロー・AI補間・顔/視線/ポーズの意味認識・写真ルック転写・ビート検出・ジャイロ・自動追尾クロップは未実装です。
- J/Lは前後1秒の移動です。逆再生シャトルは未実装です。
- CPUのlibx264を採用しています。VideoToolboxは能力を検出しますが、実機検証が済むまで自動選択しません。
- クラウドChromeで合成H.264素材の読み込み、WebGL表示、再生/停止、分割、ランプ設定、画角、ルックUndo/Redo、自動保存後の復帰と再リンク、スキャン候補表示を確認しました。全操作・音声品質・滑らかさの評価は未完了です。
- `.project` ダウンロードは検証ブラウザで完了イベントを取得できず、実機確認が必要です。自動保存の復帰とMac APIの保存/読込は検証済みです。
- 実素材の手ぶれ補正で一度、不完全な中間MP4を検出しました。元の原因は未特定です。1.1.0では中間出力の検証・限定再試行・診断ログを追加し、実素材の同条件試験は2回成功しています。

## 1.3 — 2レイヤーと直接編集

- V2（上段）とV1（下段）へクリップを配置できます。重なる区間はV2を表示します。同じ段では配列上で後のクリップ（通常は後から追加したクリップ）が優先されます。
- クリップ中央をドラッグして時刻・レイヤーを移動。両端の持ち手をドラッグしてトリミング。CUTには開始・終了スライダー、配置時刻、レイヤーの数値／選択操作もあります。
- 空いたレイヤーをタップすると貼り付け先が選ばれます。コピー、切り取り、貼り付け、複製は上部ボタンと⌘C／X／V／D（WindowsはCtrl）に対応。貼り付けは再生ヘッドへ、複製は元クリップの末尾へ配置します。
- 削除は他のクリップの位置を変えません。上段を削除すれば下段が現れます。前詰め削除は同じレイヤーで削除区間の後にあるクリップだけを詰めます。
- 吸着ボタンで境界スナップを切り替えます。ドラッグは30fps単位が基本です。Optionドラッグは複製になります。
- 1回のドラッグはUndo 1回で戻ります。⌘Z、⌘ShiftZ、CtrlY、および画面のUndo／Redoボタンに対応します。
- 原音は表示中のクリップだけを採用し、BGMは全体に流れます。上段の透明部分は下段と合成されます。
- 速度ランプを分割すると元の速度積分を保持します。速度やカーブを再指定した場合は、そのクリップ範囲で新しいランプを設定します。
- 再生用タイムラインを事前計算し、速度積分とGPU設定をキャッシュ。画面描画を最大30回／秒に抑え、ドラッグ中のサムネイル再生成を避けています。Macプロキシは引き続き利用できます。
- 旧プロジェクトは従来の並びを維持して読み込みます。2レイヤーのプロジェクトはこの版のMacエンジンで書き出してください。旧Mac版へ戻すと配置が正しく再現されません。

実機でのタッチ操作・Safariの性能・長時間4Kの性能は未確認です。Mac版のレイヤー書き出しは区間ごとに処理するため、細かく重ねるほど処理時間が増えます。元素材は変更しません。

## 1.4 — 静止画・音声の追加と素材管理

「素材を追加」から動画・静止画・音声を混在して複数選択できます。ドラッグ＆ドロップも同じ動作です。読み込めないファイルが含まれても、読み込み済みの素材は維持し、残りを続けます。

- 素材一覧：すべて／動画／静止画／音声で絞り込み、名前検索、追加順／名前順、使用箇所の数を表示。
- 静止画：JPEG・PNG・WebP。初期表示5秒、CUTや両端ドラッグで表示時間を変更。V1／V2両方に配置でき、クロップ・カラー・MP4書き出しにも対応します。透明部分は黒背景へ合成します。HEIC・RAW・GIF・SVG・TIFFはJPEG等へ変換してください。静止画には速度／手ぶれ補正／動き解析の操作を出しません。
- 大きな静止画：100MB／8,000万画素を上限にします。プレビューは長辺1280px、サムネイルは320pxに縮小。画像を切り替えると前のプレビュービットマップを解放します。ブラウザの初回読み込み時には1枚をデコードします。
- 音声：素材一覧から試聴し、「BGMに使う」で指定。追加だけでは現在のBGMを変更しません。SOUNDの選択欄で保存済み音声へ切り替え、音量／フェードを調整できます。BGMは1本を全体へループ再生します。複数音声のタイムライン配置や同時ミックスは未実装です。
- 表示名は自由に変更できます。元ファイル名は保持するため、再リンクへの影響はありません。
- 「一覧から外す」「未使用を整理」はプロジェクト内の未使用素材だけが対象です。元ファイルや端末内保存データは物理削除せず、Undoで戻せます。
- 同じ名前・サイズで接続済みの素材は重複追加しません。静止画・音声も既存の端末内保存、.project保存／再リンクの対象です。

Mac版で静止画を含む書き出しをする場合は、この版をダウンロードし直してください。iPhone実機での新しい読み込みUI・静止画書き出し・保存の確認はまだ行っていません。写真はSDR／sRGB推奨で、HDR静止画やICCプロファイルの厳密な一致は保証していません。


## 1.5.0 — 時間・静止・光・文字

- 「このフレームをV2で静止」で再生ヘッドのフレームを独立した上段クリップとして置きます。0.033〜60秒。両端ドラッグまたはスライダーで長さ変更。下段の時間とBGMは進み、上段終了後はその時点の下段へ戻ります。原音は表示優先クリップのものを使うため静止クリップの原音は無音です。
- FXで選択クリップの不透明度と透明フェードIN/OUTを調整。V2の透明部分はV1を表示し、V1の透明部分は黒になります。フェード時間は各クリップの半分までです。音声フェードは独立しています。
- FXのCAMERA FLASH（白→透明）、BLACK → IMAGE、IMAGE → BLACKを追加。FXラインで選び、開始・長さ・強さを調整、削除、Undo/Redo。最大20個。映像2段の上・文字の下に合成します。効果は映像の総尺を延ばしません。
- TEXTはRise／Slideの出入りと独立したFade in／Fade out。従来のFade設定も読み込みます。
- LOOKは8種へ再調整。説明と同じフレームのサムネイル、0〜150%の強さ、補正前後の切替。既存プロジェクトの色値は勝手に変更しません。MONOは100%以上でも色反転しません。
- GPU／端末書き出し／MacのRGB式を統一。Macはキャッシュした33³ LUTと明示的なBT.709出力変換を使用。HDRはMacのSDRプロキシを基準にします。
- 合成中の映像デコーダは最大2系統。見えない下段のフレームは描画せず、再開時点から読みます。Macは下段を一時ファイルへストリーム処理し、上段と合成して削除します。

この追加分のSafari実機操作・端末エンコーダ試験は未実施です。Macを利用する場合も新しいZIPへ更新してください。旧エンジンは追加効果を処理できません。


## 1.6.0 — 3 video / 4 audio

映像はV1・V2・V3の3段。上の段、同じ段では後に置いたクリップが優先されます。V3/V2の透明フェードから下の映像を合成します。新しく作る静止クリップはV3へ配置します。

SOUNDの「原音を音声トラックへ分離」で、動画の範囲・速度ランプ・音量・フェードを引き継いだ音声クリップを作成し、動画側をミュートします。その後は映像と音声が独立し、どちらの移動・カットも他方を変更しません。映像を消しても分離音声の素材は保持します。

音声はA1原音・A2環境音・A3 BGM・A4効果音の4段。名前・用途は自由。同じ段の重なりは後のクリップを優先し、別の段は同時再生します。中央ドラッグで位置と段、両端でトリム。コピー／貼り付け／複製／分割／削除／前詰め／Undo・Redoに対応。音量・IN/OUTフェード・速度とランプ・ループをSOUNDで調整できます。段ごとのMはミュート、Sはソロ。ソロ時は未分離の動画原音も止めます。

音声ファイルは素材一覧から配置、またはSOUNDの「音声ファイルを追加」。複数選択時は選んだ段へ順に配置します。旧プロジェクトのBGMはA3へ同じ長さ・ループ・音量で移行します。音声が映像より長い場合は、その部分を黒映像としてMP4に残します。音声だけのプロジェクトの書き出しは未対応です。

画面はウインドウの高さに合わせ、素材／設定／タイムラインをそれぞれスクロール。上部は「素材準備 → 編集 → 仕上げ → 補助」の4工程で整理しています。タイムライン操作は「履歴・クリップ・範囲・編集」に分け、分割と削除を常時見つけやすくしています。トラック名と縦スクロールを同期し、編集ツールは固定します。素材・設定の⤢でパネルを広げ、もう一度押すと戻ります。iPhoneはキーボード表示時の有効高さにも合わせ、ビューアーがタイムラインを覆わない3段構成にします。基本操作を常時表示し、コピーなどは「その他」から開けます。

Macは最大3段を一時ファイルで合成し、音声は最大4入力へまとめて混ぜます。端末版は最大3映像系統と4音声系統を使い、音声は0.25秒単位で混合します。1倍を超える原音量・極端な速度・スタビライズは処理プレビューで確認してください。端末の音声速度変更は音程も変化し、Macのatempo処理とは異なります。

今回のSafari実機レイアウト・タッチ・GPU書き出し検証は未実施です。旧Macエンジンには追加機能がないためZIPの更新が必要です。

## 1.7.0 — RESPONSE / QUALITY

- コピーしたクリップから「属性ペースト」を実行し、色・ルック、スケール・位置、速度・補間・手ぶれ補正、映像フェード、音声設定を選んで移せます。素材、配置レイヤー、開始位置、IN / OUTは保持します。`⌘ Shift V`でも開け、1回のUndoで戻せます。
- 再生中の映像・音声同期を30Hzへまとめ、FX表示の不要なDOM再生成を停止しました。下段映像の読み込み中に操作が続いた場合は、最後の要求だけを保持して処理します。
- iPhone端末書き出しの手ぶれ補正は、すでに累積されたカメラ軌跡を正しく平滑化するよう修正しました。画面周辺の複数領域から動きを推定し、人物の動きに引かれにくくしています。局所的な直線軌跡を使い、意図的なパンを残しながら細かな揺れを減らします。
- Mac版vidstabはグローバル最適化、bicubic補間、固定optzoomを明示。補正用の中間映像をCRF 10へ上げ、不要な中間音声エンコードを削除しました。
- iPhone端末書き出しは高速再生時の音声へ短い帯域制限補間を使い、折り返しノイズを抑えます。4レイヤーの合成後は左右連動のリミッターでピークを保持し、単純な波形切断を避けます。
- Mac版の速度ランプ音声は32-bit float PCMで中間処理し、最終ミックスは自動増幅を無効にしたリミッターを使用。再エンコード時のAACを48kHz・256kbpsへ固定しました。

手ぶれ補正はGoogle ResearchのL1最適カメラ軌跡の考え方と、FFmpeg／vid.stabの実装・設定を参照しています。ブラウザ版は軽量な平行移動補正、Mac版はvid.stabの回転を含む補正です。
